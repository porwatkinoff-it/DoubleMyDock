# DoubleMyDock

Лёгкая копия Дока macOS на всех мониторах, где нет настоящего Дока.

macOS показывает Док только на одном экране. DoubleMyDock ставит внизу каждого другого монитора панель с теми же программами:

- закреплённые в Доке программы (читаются из настроек Дока и обновляются сами);
- запущенные программы, которых нет среди закреплённых, — за разделителем;
- Корзина;
- размер значков берётся из настроек Дока; на macOS 26 — то же «жидкое стекло», что у системного Дока;
- точка под запущенными программами, название при наведении;
- правый клик по значку: «Показать / Скрыть», «Завершить», «Показать в Finder»;
- правый клик по пустому месту панели: «Открывать при входе», «Выйти из DoubleMyDock».

Когда вы переносите настоящий Док на другой монитор, копия сама перепрыгивает туда, где Дока теперь нет.

## Нагрузка

Один файл на Swift/AppKit, без сторонних библиотек. Программа ничего не опрашивает постоянно: список обновляется по событиям запуска и закрытия программ, а раз в 2 секунды проверяется, на каком экране сейчас настоящий Док. В простое процессор почти не используется, памяти нужно около 20–30 МБ.

## Сборка

Нужны macOS 13+ и Xcode или Command Line Tools (`xcode-select --install`).

```bash
bash build.sh
```

Скрипт соберёт `DoubleMyDock.app` (Apple Silicon и Intel), установит в `~/Applications`, запустит и сделает установочный образ `dist/DoubleMyDock.dmg`.

## Ограничения

- Копия всегда стоит внизу экрана и не сдвигает окна, как настоящий Док: развёрнутое окно может уйти под неё.
- В полноэкранных программах копия не показывается.
- Перетаскивать файлы на значки и менять порядок значков пока нельзя.
